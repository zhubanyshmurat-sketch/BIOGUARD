# BIOGUARD

**BIOGUARD: Табиғат қорғаушысы**

Мобильная обучающая игра для проекта «BIOGUARD KAZAKHSTAN». Технологии: React, TypeScript, Tailwind, framer-motion. Бэкенда нет.

## Запуск

```bash
npm install
npm run dev        # откроется на http://localhost:5173 (и в локальной сети: с телефона по Wi-Fi)
npm run build      # готовый сайт будет в папке dist/
```

Папку `dist/` можно загрузить на любой статический хостинг (Netlify Drop, GitHub Pages, Vercel). Полученную ссылку превратите в QR-код для макета.

## Где что редактировать

- **Весь контент** (виды, факты, угрозы, вопросы, тексты интерфейса, ссылка на сайт проекта `PROJECT_URL`) находится в `src/data/content.ts`.
- **Фото животных**: положите файл в `public/species/` (например `snow-leopard.jpg`) и укажите у вида `image: './species/snow-leopard.jpg'`. Если фото нет или оно не загрузилось, показывается эмодзи.
- Карта Казахстана находится в `src/components/KazMap.tsx`.

## Секретный режим презентации

Удерживайте логотип 3 секунды (на стартовом экране или в меню миссий), и все миссии откроются сразу. Повторное удержание выключает режим.

## Что хранится

- `localStorage`: лучший результат, имя игрока, вкл/выкл звука.
- `sessionStorage`: прогресс миссий, поэтому при случайном обновлении страницы прогресс не теряется.
